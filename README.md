Leonida — a GTA VI trophy guide and tracker for all 55 PlayStation 5 trophies. Every trophy gets a guide written in our own words with its sources cited beside it, plus a three-stage roadmap to the platinum, a missable-trophy warning, a localStorage tracker with export/import, kind and grade filters, and a spoiler-free mode for story trophies. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

Open `app/index.html` in a browser, or serve the `app/` folder with any static server (`node serve.ts` serves it at http://localhost:8080). No build step — plain HTML, CSS and JavaScript, fully offline. It loads nothing over the network and saves your progress in the browser only.
